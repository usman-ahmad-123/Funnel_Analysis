📊 Funnel Analysis & Customer Conversion Dashboard

An end-to-end Funnel Analysis project that analyzes user behavior across the e-commerce customer journey — from Browse → Add to Cart → Checkout → Purchase.

The project combines Python-based data analysis, statistical aggregation, visualization, Excel reporting, and Power BI dashboarding to identify conversion bottlenecks, customer drop-offs, high-performing acquisition channels, regional/device performance, revenue contribution, and time-based conversion patterns.

---

🎯 Project Objective

The primary objective of this project is to understand:

- How users move through different stages of the purchase funnel
- Where the largest customer drop-offs occur
- What percentage of users ultimately convert into customers
- Which marketing channels generate better conversions and revenue
- Which regions perform better
- How device type affects conversion performance
- How customer activity changes over time
- How much revenue is generated from converted sessions
- What actions can be taken to improve funnel performance

The analysis is designed to transform raw event-level customer data into actionable business insights.

---

🧩 Business Problem

In an e-commerce environment, attracting users is only the first step. A business needs to understand what happens after users arrive on the platform.

A typical customer journey is:

Browse
   ↓
Add to Cart
   ↓
Checkout
   ↓
Purchase

Users can drop out at any stage.

Therefore, the key business questions are:

1. How many users reach each funnel stage?
2. What is the conversion rate at each stage?
3. Where is the biggest drop-off?
4. Which marketing channel has the highest conversion rate?
5. Which region generates the most revenue?
6. Which device converts users more effectively?
7. What is the average order value?
8. What is the bounce rate?
9. When are users most active?
10. Where should the business focus its optimization efforts?

👤 3. Session-Level Aggregation

Because the raw dataset is event-level data, multiple rows can belong to the same session.

Therefore, the analysis creates a session-level summary.

For every session, the following information is retained/derived:

- User ID
- Session start
- Session end
- Events performed
- Device
- Region
- Channel
- Revenue
- Bounce flag
- Session duration

Session duration is calculated as:

Session Duration
= Session End − Session Start

The notebook then determines the maximum funnel stage reached by each session.

---

🔻 4. Funnel Stage Definition

The funnel is defined as:

Browse
   ↓
Add to Cart
   ↓
Checkout
   ↓
Purchase

For each session, the analysis identifies the furthest stage reached.

For example:

Browse

means the user only browsed.

Browse → Add to Cart

means the user reached the cart stage but did not continue.

Browse → Add to Cart → Checkout

means the user reached checkout but did not purchase.

Browse → Add to Cart → Checkout → Purchase

represents a successful conversion.

This session-level approach prevents event rows from being treated as independent customers.

🚨 13. Funnel Drop-Off Analysis

One of the most important objectives is identifying where customers leave the funnel.

The project calculates:

Drop-off Rate
= 1 − (Current Stage Sessions / Previous Stage Sessions)

The largest relative loss occurs between:

Checkout → Purchase

because only about 29.05% of checkout-reaching sessions result in a purchase.

This indicates that checkout completion is an important optimization area.

The notebook automatically identifies the stage with the maximum drop-off rate.

---

💡 14. Strategic Recommendations

The notebook generates recommendations based on the calculated metrics.

The logic focuses on:

1. Reduce the largest funnel drop-off

Investigate UX and friction at the stage with the highest drop-off.

2. Invest in the strongest acquisition channel

The best-performing channel should receive additional attention and budget, subject to business constraints.

3. Learn from high-performing regions

Strategies used in better-performing regions can be evaluated for applicability to weaker regions.

4. Improve checkout completion

Because checkout-to-purchase conversion is relatively low, checkout abandonment should be investigated.

Possible areas for business investigation include:

- Checkout usability
- Payment friction
- Unexpected costs
- Trust/security concerns
- Page performance
- Form complexity

5. Monitor cart abandonment

Users reaching Add to Cart but not continuing to Checkout represent a significant opportunity for optimization.

The notebook explicitly generates recommendations around the largest drop-off, best channel, best region, and cart abandonment.

🔍 Important Business Insight

The biggest opportunity is not simply increasing traffic.

The dataset shows substantial loss throughout the funnel:

10,000 Browse
      ↓
  6,949 Add to Cart
      ↓
  3,456 Checkout
      ↓
  1,004 Purchase

Therefore, improving the percentage of existing users who progress through the funnel can potentially create more value than focusing only on acquiring additional traffic.

In particular, the Checkout → Purchase stage deserves attention because only about 29.05% of checkout sessions become purchases.
